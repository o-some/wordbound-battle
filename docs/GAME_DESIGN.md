# GAME_DESIGN – Wordbound Battle

Wordbound Battle ist ein rundenbasiertes Sprachlern-RPG für Tula’s Island.

## Kernloop
1. Gegner-Schwäche lesen.
2. passenden Gehilfen wählen.
3. Sprachaufgabe lösen.
4. korrekte Lösung löst Angriff aus.
5. Fehler erhöhen Gegnerdruck.
6. Gegnerzug ausführen.
7. Energie/Teamzustand verwalten.

## Lernformate V2.2

Action darf die Lesbarkeit nicht überlagern. Die Sprache ist die eigentliche Kampfmechanik.
